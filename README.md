

## Project Name : FitLog

## Short Description :
FitLog is a workout tracking website. Here users can see different workouts,
check the details of each workout, and add workouts to their daily plan. 
Users can also mark a workout as done, remove it, or save it for later. 
This project is made using Next.js and Tailwind CSS.

## Technologies Used :
- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API (for managing plan and saved workouts)

## 5 Key Features :
1. Users can see all workouts in a card layout on the home page.
2. Clicking a workout card shows a details page with full information about that workout.
3. Users can add a workout to "Today's Plan" or save it for later.
4. On the My Plan page, users can mark a workout as done or remove it, and also sort workouts by duration, calories, or rating.
5. The website is fully responsive, so it works properly on mobile, tablet, and desktop. It also has a custom 404 page for wrong links.
